# E-Commerce Customer Analytics and Review Optimization

## Project Overview
This project analyzes e-commerce sales data to understand sales performance, profitability, customer ratings, and product-category trends. It uses Excel and Python to transform raw data into useful business insights.

## Objectives
- Analyze total sales and profit.
- Compare sales performance across product categories.
- Identify monthly sales trends.
- Examine customer rating distributions.
- Identify categories with a high percentage of low ratings.
- Apply statistical methods to investigate relationships in the data.
- Present findings through charts, summary tables, and dashboards.

## Tools and Technologies
- **Microsoft Excel** — Data cleaning, calculations, and PivotTables.
- **Python** — Data analysis and statistical testing.
- **Pandas** — Data manipulation and analysis.
- **SciPy** — Statistical tests.
- **Matplotlib** — Data visualization.
- **Jupyter Notebook** — Executing and documenting Python analysis.
- **Power BI** — Planned dashboard visualization.

## Project Files
- `Flipkart_Sales_Analysis_Corrected.xlsx` — Cleaned dataset.
- `flipkart_analysis.ipynb` — Python analysis notebook.
- `Flipkart_Python_Analysis_Results.xlsx` — Analysis results.
- `Flipkart_Project_KPI_Summary.xlsx` — Key performance indicators.
- `Flipkart_Python_Analysis_Report.txt` — Text report of findings.
